## 1. 项目概要

**产品名**：YiLab（"Yi" = 易，"Lab" = 实验室）

**一句话定位**：一个产品人/科技人解构易经的可交互式入门学习网站。

**双重目的**：
- **A. 自学工具**——配合用户自己的 6 个月易经学习计划（详见 `../learning-plan.md`）
- **C. 未来变现产品的雏形**——可演化为知识星球补充 / 课程载体 / 独立小产品

**核心切角**：易经作为现代人的"决策框架"，不走玄学/算命路线。

**法律红线**：v1 不涉及疾病/婚姻/生死预测；定位是义理 + 决策思维 + 文化符号。

## 2. 范围决策

### 2.1 已选路径

**路径 A：内容先行**——先做卦象浏览器 + 入门教程，不做起卦器、不做用户系统。

- ❌ 在线起卦器（Month 5 实战阶段再考虑，进 v1.5）

- ❌ 评论 / 社交功能
- ❌ 八卦详情页（可选 v1.5）

### 2.3 v1 包含

- ✅ 64 卦索引页 + 单卦详情页
- ✅ 入门教程区（知识地图 + 6 大主题章节）
- ✅ 关于页

## 4. 数据模型

### 4.1 Hexagram 类型

```typescript
type Hexagram = {
  id: number;              // 1-64 卦序
  name: string;            // 乾、坤、屯…
  pinyin: string;          // qián, kūn…
  unicode: string;         // ䷀ ䷁（U+4DC0 起）
  binary: string;          // "111111"（六爻自下而上）
  trigrams: {
    upper: TrigramId;      // 上卦
    lower: TrigramId;      // 下卦
  };

  // 经文（古文原文，固定）
  judgment: string;        // 卦辞
  image: string;           // 大象传
  lines: Array<{           // 6 条爻辞
    position: 1 | 2 | 3 | 4 | 5 | 6;
    yinyang: 'yin' | 'yang';
    text: string;
  }>;

  // 现代解读（核心资产）
  judgmentModern: string;       // 卦辞现代解读
  imageModern: string;          // 大象传现代解读
  lineModerns: string[];        // 6 条爻辞现代解读
  decisionFramework: string;    // ★ 决策框架视角
  exampleScenarios?: string[];  // 现代场景举例（可选）

  // 自动算出来的关联
  related: {
    inverse: number;       // 综卦
    opposite: number;      // 错卦
    nuclear: number;       // 互卦
  };
};
```

### 4.2 数据来源

- **古文部分**（卦辞/爻辞/大象）：用 GitHub 上开源易经 JSON 数据集，整理后入库
- **现代解读部分**：用户原创内容（用 AI 辅助打初稿，自己审稿改写）

### 4.3 内容生产策略

**渐进发布 + 公开学习**——v1 上线时只完整写完前 8 卦深度解读：

```
v1 上线时：
├── 古文：64 卦完整
├── 现代解读：8 卦（乾/坤/屯/蒙/需/讼/师/比）
└── 其他 56 卦：标"待更新 · 计划于 YYYY-MM 完成"
```

更新节奏：每周 1-2 卦深度解读 → 半年内全部完成。

**理由**：
- v1 上线快（不卡在内容上）
- 强迫用户持续学习（产出即学习）
- 给读者"追更"期待感（连载即流量）
- 是"产品人学易经"切角的真实表达——和读者一起学，不是站在大师位置教

### 4.4 决策框架视角风格

**混合型（C）**：先 2-3 个决策检查点 + 后接现代场景类比。

举例（乾卦）：

> **决策检查点**
> 1. **时位**：你现在处于哪一爻？潜（隐藏期）/ 见（显现期）/ 跃（试探期）/ 飞（当道期）/ 亢（过盛期）
> 2. **应位**：是否有合适的"应"——共事者、机会、时机？
> 3. **变动方向**：进、退、守，哪个最配当下时位？
>
> **现代场景类比**
> 乾卦六爻像极了一段创业旅程：潜龙是 idea 阶段、见龙是 MVP、惕龙是 PMF 验证、跃龙是 scaling、飞龙是行业领导、亢龙是过度扩张……

## 5. 技术栈

| 维度 | 选择 | 理由 |
|---|---|---|
| **框架** | Next.js 16 + React 19 | 与 hoopy-site 一致 |
| **静态导出** | `output: 'export'` | 纯静态站，匹配 Cloudflare Pages |
| **语言** | TypeScript | 默认 |
| **内容** | MDX | Markdown + React 组件嵌入 |
| **样式** | CSS Modules + CSS Variables | 与 hoopy-site 一致，不引 Tailwind |
| **数据存储** | 静态 JSON / TS 常量 | 64 卦数据小，无需数据库 |
| **渲染** | SSG（静态生成） | v1 无用户态，全部预渲染 |
| **部署** | **Cloudflare Pages** | 免费额度足、国内可访问 |
| **域名** | 先 `*.pages.dev` 占位 | 用户后续定 |

**重要**：Next.js 16 是新版本，存在破坏性变更。开发前需查 `node_modules/next/dist/docs/` 中的相关指南。

**未来扩展**：如需加用户系统，可加 Cloudflare Workers + D1（v2 再考虑）。

## 6. 视觉设计系统

### 6.1 风格基调

**「数字宋本」**——三种东西的融合：

```
《编辑型杂志版式》    asymmetric grid + drop caps + pull quotes
       +
《极简单色规训》     纯黑/米/无阴影/直角/细 hairline 分割
       +
《古籍味温度》       米色纸底 + 一抹朱砂 + 墨色
```

不走"古风国潮"，不走"赛博科技"，走"电子时代的宋版书"。

### 6.2 色板（仅 8 色，不允许加任何其它颜色）

| 角色 | 色值 | 备注 |
|---|---|---|
| Background（米纸） | `#FBF7EE` | 暖米黄底，非纯白 |
| Foreground（墨色） | `#1A1714` | 偏暖深墨，非纯黑 |
| Card | `#FFFFFF` | 内容卡片用纯白 |
| Muted | `#6B6359` | 暖灰，似褪色墨 |
| Border | `#E8DFCE` | 米色细边 |
| Accent · 朱砂 | `#B23A2E` | 印章红，仅用于强调 |
| Accent · 墨青 | `#355C7D` | 用于卦象图、爻位编号 |
| Destructive | `#DC2626` | 错误状态（少用） |

### 6.3 字体栈

| 用途 | 字体 | 备注 |
|---|---|---|
| 中文标题 | **霞鹜文楷 LXGW WenKai** | 开源，手写感 |
| 中文正文 | Noto Serif SC | 屏幕可读宋体 |
| 英文标题 | Playfair Display | 编辑感 |
| 英文正文 | Source Serif 4 | 配 Noto Serif SC |
| 编号/爻位/二进制 | JetBrains Mono | "科技人"切角 |

**纪律**：全部 serif/mono，0 sans-serif。

### 6.4 视觉效果规则

- **Zero border-radius**——所有元素直角
- **No shadows**——平面如纸上墨迹
- **Hairline 1px** `#E8DFCE` 用作分割
- **Drop caps** 用于章节首字（朱砂红、4em）
- **纸纹噪点** `opacity: 0.025` 叠 background
- **六爻图** 1.5px 墨色线条，纯几何
- **Hover** 朱砂色下划线浮现（200ms ease-out）
- **Section dividers** `4px solid #1A1714` 全宽

### 6.5 字号系统

```css
--type-display:  64px;    /* 首页主标题 */
--type-h1:       40px;    /* 章节大标题 */
--type-h2:       28px;    /* 卦名 */
--type-h3:       20px;    /* 小节标题 */
--type-body:     17px;    /* 正文（中文宋体在屏幕略大） */
--type-small:    14px;    /* 注释、爻位标签 */
--type-mono:     13px;    /* 编号、二进制、code */
```

行高：正文 1.75，标题 1.2-1.4。中文 letter-spacing 0。

### 6.6 间距系统（8pt 制）

```
4 / 8 / 16 / 24 / 32 / 48 / 64 / 96 / 128
```

容器最大宽度：阅读型页面 720px，索引/导航型 1080px。

## 8. 错误处理与边界

- **数据缺失**（某卦解读未写）：显示古文 + "解读待更新 · 计划于 YYYY-MM" 标注，不显示空白
- **路由不存在**：自定义 404 页，复用主视觉，提供"返回卦象索引"链接
- **图像失败**：所有卦象用 SVG 内联渲染，不依赖外部图片
- **字体加载失败**：fallback 到系统 serif（`font-display: swap`）

## 9. 测试策略（v1 简化）

- **手动验收**：在 375 / 768 / 1440 三档分辨率下走核心路径（首页 → 索引 → 详情 → 教程）
- **可访问性**：keyboard-nav、focus-state、对比度（朱砂 vs 米色 ≥ 4.5:1）
- **构建检查**：`next build && next export` 通过
- **Lighthouse**：Performance ≥ 90、Accessibility ≥ 95
- **不做单元测试**（v1 几乎无逻辑，全静态内容）
